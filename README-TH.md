# TitanBot ภาษาไทย

เวอร์ชันนี้ปรับข้อความเมนู ปุ่ม คำอธิบายคำสั่ง และข้อความแจ้งเตือนจำนวนมากเป็นภาษาไทย รวมถึงระบบช่วยเหลือ เลเวล เงิน ร้านค้า วันเกิด Ticket ใบสมัคร ยืนยันตัวตน ต้อนรับ เพลง และการดูแลสมาชิก

ชื่อคำสั่ง / ชื่อพารามิเตอร์ ID ปุ่ม และโครงสร้างฐานข้อมูลยังใช้รูปแบบเดิม ข้อความที่ตั้งค่าไว้ในฐานข้อมูลเดิมจะไม่ถูกเขียนทับ ข้อความจากบริการภายนอก ชื่อเพลง และคำค้นอาจเป็นภาษาต้นฉบับ แปลข้อความแบบไดนามิกในระบบหลักเพิ่มเติมแล้ว ข้อความจากระบบภายนอกและข้อความเฉพาะบางกรณีอาจยังเป็นภาษาอังกฤษ

## ติดตั้งใหม่

1. ติดตั้ง Node.js 22 หรือใหม่กว่า และ PostgreSQL
2. แตกไฟล์ ZIP แล้วเปิด Terminal ในโฟลเดอร์ที่มี `package.json`
3. ติดตั้งแพ็กเกจด้วย `npm ci`
4. คัดลอก `.env.example` เป็น `.env`
5. ใส่ `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID` และ `OWNER_IDS` ของคุณ โดย OWNER_IDS ใส่เฉพาะตัวเลข ID ถ้ามีหลายคนให้คั่นด้วยจุลภาค
6. สร้างฐานข้อมูล PostgreSQL และตั้ง `POSTGRES_URL` ให้ตรงกับฐานข้อมูลของคุณ เช่น `postgresql://postgres:YOUR_PASSWORD@localhost:5432/titanbot`
7. ใน Discord Developer Portal เปิด Server Members Intent และ Message Content Intent แล้วเชิญบอทด้วย scope `bot` และ `applications.commands` พร้อมสิทธิ์ตามระบบที่ใช้
8. รัน `npm start`
9. ใน Discord ใช้ `/configwizard` เพื่อตั้งค่าเริ่มต้น จากนั้นใช้ `/commands dashboard` เพื่อเปิดระบบ และ `/help` เพื่อดูคำสั่ง

ระบบเพลงต้องตั้งค่า Lavalink เพิ่มเติม อ่านการตั้งค่าต้นฉบับใน README.md และ .env.example

## อัปเดตจากเวอร์ชันเดิม

หยุดบอทและสำรองฐานข้อมูลก่อนเปลี่ยนไฟล์ ใช้ `.env` เดิมและฐานข้อมูลเดิม แล้วรัน `npm ci` และ `npm start` บอทจะลงทะเบียนคำอธิบายคำสั่งใหม่เมื่อเริ่มทำงาน ไม่มีการเปลี่ยนสคีมาฐานข้อมูลสำหรับการแปลนี้

ข้อความต้อนรับ เลเวลอัป และแผงที่เคยตั้งค่าไว้ในฐานข้อมูลยังเป็นค่าเดิม สามารถแก้เป็นไทยผ่านแผงตั้งค่าของแต่ละระบบได้ แผงข้อความที่โพสต์ไว้ก่อนอัปเดตอาจต้องส่งใหม่

## การตรวจสอบ

ตรวจไวยากรณ์ JavaScript ทุกไฟล์ และเปรียบเทียบชื่อคำสั่ง ชื่อพารามิเตอร์ ID ปุ่ม และ URL กับไฟล์ต้นฉบับ ไม่ได้เข้าสู่ระบบ Discord หรือทดสอบเชื่อมฐานข้อมูลจริง เนื่องจากไม่มีข้อมูลเชื่อมต่อของคุณ

ไฟล์ต้นฉบับ LICENSE และเครดิตโครงการยังอยู่ครบ

## อัปเดตการแปล รอบที่ 2

- เพิ่มข้อความไทยในตัวช่วยตั้งค่าผ่าน DM รวมถึงขั้นตอน คำถาม การบันทึก และการแจ้งข้อผิดพลาด
- เพิ่มข้อความไทยใน Ticket การปิด เปิดใหม่ รับผิดชอบ ลบ และประเมินการช่วยเหลือ รวมถึงหัวตารางไฟล์ประวัติข้อความ HTML
- เพิ่มข้อความประกาศผู้ชนะกิจกรรม การสุ่มใหม่ และผลการรับสมัคร
- เพิ่มข้อความในระบบเพลง คิว เล่นวน ระดับเสียง และการเชื่อมต่อห้องเสียง
- เพิ่มข้อความผลการทำงาน ฝาก ถอน ซื้อไอเทม เดิมพัน และข้อจำกัดการซื้อ พร้อมชื่อไอเทมภาษาไทย
- เพิ่มชื่อหมวดไทยในเมนูช่วยเหลือและแผงสิทธิ์คำสั่ง โดยเก็บชื่อหมวดที่ใช้กับฐานข้อมูลและโฟลเดอร์เป็นค่าเดิม
- รองรับการแยกประเภทข้อผิดพลาดที่เป็นภาษาไทย และรักษาข้อความท้ายที่แจ้งเวลาปิดหรือเลขหน้า

ตรวจ JavaScript ผ่านครบ 272 ไฟล์ ตรวจชื่อคำสั่ง พารามิเตอร์ ID ปุ่ม ค่าเมนู และ URL กับเวอร์ชันก่อนหน้า ผ่านการตรวจพฤติกรรมการแปลและความเข้ากันได้ 27 ข้อ และตรวจว่า ID ราคา ผลไอเทมกับเงื่อนไขซื้อยังเหมือนเดิม

ยังไม่ได้ทดสอบออนไลน์ใน Discord หรือเชื่อมต่อ PostgreSQL จริง
